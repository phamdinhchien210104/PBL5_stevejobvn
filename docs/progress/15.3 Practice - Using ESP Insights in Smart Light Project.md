> **Bố cục phân vùng Flash (4MB)**:
> - `0x000000` - Bootloader (32KB)
> - `0x008000` - Partition Table (4KB)
> - `0x00D000` - `sec_cert` (12KB, Reserved Secure Certs)
> - `0x010000` - `nvs` (24KB, Wi-Fi & System NVS)
> - `0x016000` - `otadata` (8KB, OTA selection)
> - `0x018000` - `phy_init` (4KB, RF calibration)
> - `0x020000` - `ota_0` (1920KB, Slot 0 Active Firmware)
> - `0x200000` - `ota_1` (1920KB, Slot 1 OTA Firmware)
> - `0x3E0000` - `fctry` (24KB, Factory Manufacturing NVS Credentials)
> - `0x3E6000` - `coredump` (64KB, ELF Crash Dump Storage)
> - `0x3F6000` - Cuối Flash 4MB (40KB dự phòng an toàn)
