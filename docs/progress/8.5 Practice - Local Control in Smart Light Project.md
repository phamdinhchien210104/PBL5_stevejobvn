## 1. Mục Đích & Yêu Cầu Cốt Lõi Của Mục 8.5 Practice

Mục **8.5 Practice: Local Control in Smart Light Project** yêu cầu triển khai cơ chế **điều khiển cục bộ (Local Control) qua mạng nội bộ LAN hoặc Bluetooth LE** mà không phụ thuộc vào kết nối Internet hay máy chủ đám mây (Cloud). Khi đường truyền Internet ra bên ngoài (WAN) bị mất hoặc router gặp sự cố, ứng dụng điện thoại hoặc kịch bản máy tính vẫn có thể tự động tìm thấy đèn và điều khiển bật/tắt tức thì với độ trễ siêu thấp (<20ms).

Phần thực hành này hướng dẫn triển khai 3 nhóm tính năng kỹ thuật chính:
1. **Mục 8.5.1: Xây dựng Local Control Server trên nền Wi-Fi + HTTPS**:
   - Sử dụng component `esp_local_ctrl` của ESP-IDF biến đèn thành máy chủ HTTPS an toàn trên cổng 443.
   - Quảng bá khám phá thiết bị qua mDNS: `mdns_init()` và `mdns_hostname_set("my_esp_ctrl_device")` $\rightarrow$ cho phép client truy cập qua tên miền cục bộ `https://my_esp_ctrl_device.local`.
   - Nạp chứng chỉ bảo mật TLS X.509 (`cacert.pem`) và khóa riêng tư RSA (`prvtkey.pem`).
   - Đăng ký thuộc tính điều khiển đèn `status` với các hàm callback đọc (`get_prop_values`) và ghi (`set_prop_values`).
2. **Mục 8.5.2: Kịch bản Script kiểm thử chức năng**:
   - Xây dựng kịch bản Python client tự động (`test_case/local_control/scripts/test_local_control.py`) gửi yêu cầu GET/POST HTTPS nội bộ để kiểm tra thay đổi trạng thái đèn và xác nhận phản hồi JSON.
3. **Mục 8.5.3: Thiết lập Local Control Server qua kênh Bluetooth LE (GATT Server)**:
   - Triển khai phương án dự phòng điều khiển nội bộ khi router Wi-Fi không hoạt động hoặc không có mạng Wi-Fi.
   - Khởi tạo GATT Server, khai báo Service UUID `0x00FF`, Characteristic Ghi lệnh (UUID `0x0001`, Writable) và Đọc trạng thái (UUID `0x0002`, Readable).
   - Lắng nghe sự kiện `GATT_WRITE_EVT` từ smartphone để điều khiển đèn bật/tắt trực tiếp qua Bluetooth.

## 4. Chi Tiết Kỹ Thuật Các Kênh Điều Khiển Cục Bộ

### 4.1. Kênh Wi-Fi HTTPS + mDNS (Mục 8.5.1)
- **Tên miền mDNS nội bộ**: `my_esp_ctrl_device.local`.
- **Cổng kết nối**: Cổng bảo mật `443` (HTTPS TLS 1.2/1.3).
- **Endpoint phục vụ**:
  - `GET https://my_esp_ctrl_device.local/esp_local_ctrl/version`: Trả về phiên bản giao thức local control.
  - `GET https://my_esp_ctrl_device.local/esp_local_ctrl/control`: Đọc danh sách và giá trị các thuộc tính (trả về JSON `{"status": true}` hoặc `{"status": false}`).
  - `POST https://my_esp_ctrl_device.local/esp_local_ctrl/control`: Gửi payload cập nhật thuộc tính đèn.

### 4.2. Kịch Bản Kiểm Thử Tự Động Bằng Python (Mục 8.5.2)
Kịch bản [`test_case/local_control/scripts/test_local_control.py`](file:///d:/Document/PBL5_stevejobvn/test_case/local_control/scripts/test_local_control.py) được tối ưu hóa bằng thư viện `urllib` tiêu chuẩn (không cần cài thêm `requests`), hỗ trợ bỏ qua kiểm tra chứng chỉ tự ký (self-signed):
```bash
# Chạy kiểm thử qua mDNS:
python test_case/local_control/scripts/test_local_control.py --host my_esp_ctrl_device.local

# Hoặc chạy kiểm thử qua địa chỉ IP trực tiếp:
python test_case/local_control/scripts/test_local_control.py --host 192.168.1.31
```

### 4.3. Kênh Dự Phòng Bluetooth LE GATT (Mục 8.5.3)
Khi router Wi-Fi bị ngắt điện hoặc thiết bị được mang ra ngoài khu vực phủ sóng Wi-Fi:
- Đèn phát quảng bá BLE với tên: **`ESP32-LOCAL-LIGHT`**.
- Người dùng mở ứng dụng kiểm thử Bluetooth trên điện thoại (ví dụ: **nRF Connect**, **LightBlue**, hoặc ứng dụng tự phát triển).
- Kết nối vào thiết bị và điều khiển:
  - Chọn **Service UUID `0x00FF`**.
  - Chọn **Characteristic `0x0001` (Write)** $\rightarrow$ Gửi giá trị `0x01` để **BẬT ĐÈN**; Gửi `0x00` để **TẮT ĐÈN**.
  - Chọn **Characteristic `0x0002` (Read)** $\rightarrow$ Đọc giá trị byte trạng thái (`0x01` = Bật, `0x00` = Tắt).

## 6. Tổng Kết Trạng Thái Hạng Mục 8.5 & Sẵn Sàng Kế Thừa Sang Chương 9

### 6.1. Đánh Giá Mức Độ Hoàn Thành
- Toàn bộ các mục tiêu của **Mục 8.5 Practice: Local Control in Smart Light Project** đã được hiện thực hóa 100% với kiến trúc hiện đại, sạch sẽ và phẳng hóa logic.
- Khắc phục toàn diện các lỗi cũ trong giáo trình:
  1. Loại bỏ các ký tự dấu ngoặc kép tiếng Trung gây lỗi biên dịch nghiêm trọng.
  2. Sửa lỗi `CMakeLists.txt` liên quan đến việc nhúng chứng chỉ TLS (`EMBED_TXTFILES`).
  3. Kế thừa đồng nhất driver WS2812B Hardware SPI2 DMA @ 3.2MHz trên GPIO 4 và Nút Boot HAL.
  4. Hỗ trợ song song cả Wi-Fi HTTPS Local Control và BLE GATT Local Control trong cùng một firmware đồng nhất.
  5. Cung cấp kịch bản Python client tự động kiểm thử nhanh chóng và tin cậy.
  6. **Hiện đại hóa chứng chỉ HTTPS trên ESP-IDF v6.0.2**: Chuyển đổi từ `https_conf.cacert_pem` sang `https_conf.servercert` và `servercert_len` để nạp đúng chứng chỉ X.509 cho máy chủ HTTPS nội bộ, loại bỏ hoàn toàn lỗi runtime `No Server certificate supplied` và crash reboot.

### 6.2. Sẵn Sàng Kế Thừa Sang Chương 9 (`device_firmware/5_rainmaker`)
Với nền tảng Điều Khiển Cục Bộ (Chương 8) đã hoàn thiện vững chắc, hệ thống sẵn sàng kế thừa sang **Chương 9: Remote Control through ESP RainMaker** tại thư mục `device_firmware/5_rainmaker` để kết nối điều khiển đám mây (Cloud) qua AWS IoT và ứng dụng di động ESP RainMaker!
