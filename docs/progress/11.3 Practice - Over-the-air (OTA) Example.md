## 1. Mục Đích & Yêu Cầu Cốt Lõi Của Mục 11.3 Practice

Nâng cấp firmware qua mạng không dây (Over-the-Air - OTA) là tính năng sống còn đối với mọi thiết bị IoT thương mại. Mục **11.3 Practice: Over-the-air (OTA) Example** giải quyết triệt để 2 bài toán lớn nhất trong vận hành IoT:
1. **Loại bỏ nguy cơ biến thiết bị thành "cục gạch" (Anti-Brick Protection)**:
   - Kích hoạt cơ chế **Bootloader App Rollback** (`CONFIG_BOOTLOADER_APP_ROLLBACK_ENABLE=y`).
   - Thiết kế phân vùng bộ nhớ Flash kép song song: `ota_0` và `ota_1` (mỗi phân vùng 1920KB, căn chỉnh ranh giới sector 64KB) cùng bảng dữ liệu chuyển mạch phân vùng `otadata` (8KB).
   - Khi vừa tải xong firmware mới, bootloader đưa phân vùng mới vào trạng thái `ESP_OTA_IMG_PENDING_VERIFY`. Nếu firmware mới gặp lỗi nghiêm trọng (crash, panic, loop reboot, watchdog reset) hoặc không vượt qua khâu chẩn đoán phần cứng, bootloader sẽ tự động quay trở về phân vùng firmware cũ còn hoạt động ổn định trên lần khởi động tiếp theo.
2. **Cơ chế chẩn đoán sức khỏe sau cập nhật (Post-OTA Diagnostics Checkpoint)**:
   - Tuân thủ nghiêm ngặt nguyên mẫu chuẩn của ESP RainMaker (`esp_rmaker_post_ota_diag_t`):
     ```c
     static esp_rmaker_ota_diag_status_t app_ota_diagnostic(esp_rmaker_ota_diag_priv_t *ota_diag_priv, void *priv);
     ```
   - **Giai đoạn 1 (`OTA_DIAG_STATE_INIT`)**: Kiểm tra phần cứng WS2812B, phát xung đèn nháy báo hiệu trực quan, kiểm tra tính toàn vẹn bộ nhớ NVS Flash. Trả về `OTA_DIAG_STATUS_SUCCESS`.
   - **Giai đoạn 2 (`OTA_DIAG_STATE_POST_MQTT`)**: Kiểm tra bắt tay thành công với RainMaker Cloud qua MQTT TLS, sau đó chính thức gọi hủy rollback (`esp_ota_mark_app_valid_cancel_rollback()`).
3. **Linh hoạt hỗ trợ 2 phương thức kích hoạt OTA**:
   - `OTA_USING_PARAMS`: Kích hoạt nâng cấp qua URL tham số (phù hợp giai đoạn thử nghiệm nội bộ, developer dùng RainMaker CLI hoặc local HTTP server).
   - `OTA_USING_TOPICS`: Kích hoạt nâng cấp hàng loạt theo chiến dịch tập trung thông qua MQTT Topic trên ESP RainMaker Cloud Dashboard.
   - Cung cấp menu lựa chọn linh hoạt qua file cấu hình `main/Kconfig.projbuild`.
4. **Hệ sinh thái kiểm thử hoàn chỉnh**:
   - Phát triển máy chủ kiểm thử cục bộ `scripts/test_ota_server.py` hỗ trợ Range requests (HTTP 206 Partial Content), quét tự động IP LAN, và tính toán bảng mã băm SHA256 / MD5.
   - Hiện đại hóa dự án kiểm thử độc lập `test_case/advanced_https_ota` với logic chẩn đoán phần cứng trên GPIO 4 và xác minh rollback.

## 4. Hướng Dẫn Thực Nghiệm Nạp Mạch & Kiểm Thử OTA Cho Người Dùng

Để trực tiếp kiểm chứng cơ chế OTA Upgrade và Rollback trên phần cứng thật:

### Bước 1: Nạp Firmware Ban Đầu (v1.0.0)
Nạp bản firmware gốc vào phân vùng `ota_0` của ESP32:
```powershell
idf.py -C device_firmware/5_rainmaker -p COMx flash monitor
```
Quan sát terminal:
- Thiết bị khởi động và in log: `[OTA Diagnostic] Post-OTA Health Check (State: 0)`.
- Trạng thái ban đầu: Bootloader chọn phân vùng `ota_0` ở địa chỉ `0x20000`.

### Bước 2: Tạo Bản Vá Firmware Mới (v1.1.0)
1. Mở file `device_firmware/5_rainmaker/CMakeLists.txt`, sửa version:
   ```cmake
   set(PROJECT_VER "1.1.0")
   ```
2. (Tùy chọn) Chỉnh sửa màu mặc định của đèn trong `device_firmware/5_rainmaker/main/app_driver.c` hoặc hiệu ứng để dễ nhận diện bằng mắt thường.
3. Biên dịch bản firmware mới:
   ```powershell
   idf.py -C device_firmware/5_rainmaker build
   ```
   File binary đầu ra nằm tại: `device_firmware/5_rainmaker/build/5_rainmaker.bin`.

### Bước 3: Khởi Chạy Máy Chủ OTA Cục Bộ
Mở một cửa sổ PowerShell riêng biệt và chạy:
```powershell
python scripts/test_ota_server.py --dir device_firmware/5_rainmaker/build
```

### Bước 4: Kích Hoạt Nâng Cấp OTA Qua RainMaker CLI
Truyền URL cập nhật tới Node ID của thiết bị:
```powershell
python rainmaker.py otaupgrade <YOUR_NODE_ID> http://192.168.1.15:8070/5_rainmaker.bin
```

### Bước 5: Theo Dõi Quá Trình Nâng Cấp & Rollback
Quan sát Serial Monitor của chip ESP32:
1. **Tiến trình tải về**: `RMAKER_OTA: Starting OTA ... OTA Status: IN_PROGRESS`.
2. **Ghi Flash**: Thiết bị tải từng đoạn gói tin và ghi vào phân vùng đối ứng `ota_1`.
3. **Tự động Reboot**: Sau khi xác thực chữ ký và checksum toàn vẹn, chip phát lệnh khởi động lại.
4. **Bootloader Checkpoint**: Bootloader đọc `otadata` và chọn khởi động từ `ota_1` với cờ `ESP_OTA_IMG_PENDING_VERIFY`.
5. **Chẩn đoán Phần Cứng (`app_ota_diagnostic`)**:
   - Firmware v1.1.0 phát xung đèn LED xanh lá trên GPIO 4 xác nhận driver WS2812B hoạt động.
   - Kiểm tra bộ nhớ NVS Flash.
   - Bắt tay thành công với RainMaker Cloud MQTT.
   - Gọi `esp_ota_mark_app_valid_cancel_rollback()` $\rightarrow$ Phân vùng chính thức chuyển sang trạng thái `VALID`. Bản nâng cấp thành công mỹ mãn!
