### 3.3. Cơ Chế Đồng Bộ Hóa Bất Đồng Bộ Với FreeRTOS Event Groups

Quá trình kết nối Wi-Fi cần thời gian để phát sóng vô tuyến, dò tìm AP, bắt tay 4 bước WPA2 và gửi gói tin DHCP Discover/Offer/Request/Ack để nhận địa chỉ IP. Việc sử dụng vòng lặp chờ tích cực (busy-waiting) sẽ gây lãng phí chu kỳ CPU và ngăn cản các tác vụ thời gian thực khác.

Do đó, chương trình sử dụng **FreeRTOS Event Groups**:
```c
/* Khởi tạo nhóm cờ sự kiện */
s_wifi_event_group = xEventGroupCreate();

/* Tác vụ app_main chuyển sang trạng thái Block (ngủ không tốn CPU) chờ cờ */
EventBits_t bits = xEventGroupWaitBits(s_wifi_event_group,
                                       WIFI_CONNECTED_BIT | WIFI_FAIL_BIT,
                                       pdFALSE,
                                       pdFALSE,
                                       portMAX_DELAY);

/* Ngay khi Event Handler bắt được IP_EVENT_STA_GOT_IP hoặc quá 5 lần retry */
// -> Gọi xEventGroupSetBits() đánh thức tác vụ ngay lập tức với độ trễ micro-giây
```

### 3.4. Hệ Thống Phản Hồi Trực Quan (Visual LED Feedback)

Thiết bị đèn thông minh giao tiếp trực tiếp với người dùng qua thanh 8 hạt LED NeoPixel:

```c
void app_driver_set_wifi_status(wifi_status_t status)
{
    switch (status) {
    case WIFI_STATUS_CONNECTING:
        // Đang kết nối hoặc tự động kết nối lại: Đèn thở nhịp nhàng màu Vàng/Cam
        light_driver_set_switch(true);
        light_driver_breath_start(255, 160, 0);
        break;

    case WIFI_STATUS_CONNECTED:
        // Đã nhận được IP từ Router: Dừng thở và bật màu Xanh lá cây
        light_driver_breath_stop();
        light_driver_set_switch(true);
        light_driver_set_rgb(0, 255, 0);
        break;

    case WIFI_STATUS_FAILED:
        // Mất kết nối hoặc sai mật khẩu sau 5 lần thử: Báo Đỏ cảnh báo
        light_driver_breath_stop();
        light_driver_set_switch(true);
        light_driver_set_rgb(255, 0, 0);
        break;
    }
}
```

## 4. Tổng Quan Giai Đoạn 7.5.2: Cấu Hình Mạng Thông Minh (Smart Provisioning)

Sau khi hoàn thành 7.5.1, dự án sẽ tiến sang **Giai đoạn 7.5.2** (Chương 4 — thư mục `device_firmware/4_network_config`):
1. **Trình quản lý Cấp phát (`wifi_prov_mgr`)**:
   - Kiểm tra `wifi_prov_mgr_is_provisioned()`: Nếu đã cấu hình thì lấy thông tin từ NVS Flash kết nối thẳng; nếu chưa thì kích hoạt dịch vụ BLE.
2. **Giao tiếp Bluetooth LE & Mã QR Code**:
   - Mạch phát sóng BLE với tên dạng `PROV_XXXXXX` và in mã QR Code trực tiếp lên terminal màn hình máy tính.
3. **Thao tác Ứng dụng Điện thoại**:
   - Sử dụng App **ESP BLE Provisioning** quét mã QR, nhập Proof of Possession (POP: `abcd1234`), quét danh sách Wi-Fi xung quanh và gửi mật khẩu xuống chip qua sóng BLE.
4. **Giải phóng tài nguyên (De-initialization)**:
   - Khi nhận sự kiện `WIFI_PROV_END` và có IP thành công, hàm `wifi_prov_mgr_deinit()` sẽ tắt hoàn toàn Bluetooth để tiết kiệm RAM cho ứng dụng đèn.

## 5. Hướng Dẫn Kiểm Thử Thực Tế Cho Giai Đoạn 7.5.1

### 5.1. Cấu hình Wi-Fi qua `menuconfig`
```powershell
idf.py -C device_firmware/3_wifi_connection menuconfig
```
- Điều hướng đến menu **Example Configuration**:
  - `WiFi SSID`: Nhập tên Access Point Wi-Fi của bạn.
  - `WiFi Password`: Nhập mật khẩu Wi-Fi.
- Bấm `S` để lưu và `ESC` để thoát.

### 5.2. Nạp và theo dõi trên bo mạch thật
```powershell
# Nạp xuống bo mạch ESP32-S3 (hoặc ESP32-C3)
idf.py -C device_firmware/3_wifi_connection -p COM4 flash monitor
```
