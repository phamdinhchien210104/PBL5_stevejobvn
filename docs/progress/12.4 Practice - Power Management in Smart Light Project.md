## 1. Executive Summary

Chapter 12 implements comprehensive Power Management for the Smart Light system. The objective is to achieve Energy Star / commercial IoT standby efficiency (< 2–5 mA in idle/sleep) while maintaining active Wi-Fi/BLE network connectivity and preventing glitches or interruptions on the WS2812B NeoPixel hardware LED driver.

### Core Architectural Features:
1. **Dynamic Frequency Scaling (DFS)**: Automatically scales CPU frequency between **40 MHz** (when idle) and **160 MHz** (during heavy processing/crypto).
2. **Automatic Light-sleep with FreeRTOS Tickless Idle**: Suspends CPU execution, digital core, and high-speed clocks during idle intervals between FreeRTOS tasks.
3. **Modem-sleep (Wi-Fi/BLE)**: Synchronizes RF activity with router DTIM beacon intervals, powering down radio hardware between beacons.
4. **Power Management Lock (`ESP_PM_NO_LIGHT_SLEEP`)**:
   - **Light ON**: Acquires `s_light_pm_lock` ("light_led_lock") to prohibit Light-sleep and guarantee uninterrupted APB clocks for WS2812B Hardware SPI2 DMA.
   - **Light OFF**: Releases `s_light_pm_lock`, allowing the chip to immediately enter Automatic Light-sleep and drop current consumption to < 2–5 mA.
5. **Instantaneous GPIO Wakeup**: Boot button (GPIO 9 on C3 / GPIO 0 on S3) configured as a Light-sleep wakeup source via `gpio_wakeup_enable()` and `esp_sleep_enable_gpio_wakeup()`.

## 3. Power Consumption Benchmarks

| Device State | Operating Conditions | Target Current Range | Hardware Behavior |
| :--- | :--- | :--- | :--- |
| **Light ON (Active)** | 8x WS2812B LEDs illuminated, CPU @ 40–160 MHz, Wi-Fi connected | **20 mA – 80 mA** (plus LED current ~15mA/LED) | PM Lock held (`ESP_PM_NO_LIGHT_SLEEP`); Light-sleep prohibited; APB bus clocked continuously |
| **Light OFF (Standby)**| LEDs dark, CPU in Automatic Light-sleep, Wi-Fi in Modem-sleep | **< 2 mA – 5 mA** | PM Lock released; FreeRTOS Tickless Idle active; chip wakes only on Wi-Fi DTIM beacon or Button GPIO |
| **Button Interaction** | User presses Boot button while in Light-sleep | Instantaneous wake (< 1 ms) | GPIO interrupt wakes CPU from Light-sleep, acquires PM lock, toggles LED state |
