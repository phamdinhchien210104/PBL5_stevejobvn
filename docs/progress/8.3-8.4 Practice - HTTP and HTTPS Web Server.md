## 1. Mục Đích & Yêu Cầu Cốt Lõi Của Mục 8.3 & 8.4

Mục **8.3 HTTP Server** và **8.4 HTTPS Server** trong giáo trình hướng dẫn xây dựng một máy chủ web nhúng ngay trên vi điều khiển ESP32-C3 để cho phép bất kỳ thiết bị nào có trình duyệt web hoặc ứng dụng mạng trong cùng mạng Wi-Fi (LAN) có thể điều khiển trực tiếp đèn thông minh:
1. **Mục 8.3 HTTP Web Server (Plaintext, Cổng 80)**:
   - Sử dụng component `esp_http_server` để lắng nghe các yêu cầu HTTP tiêu chuẩn.
   - Định tuyến các URI:
     - `GET /`: Trả về giao diện web HTML để người dùng tương tác trực quan.
     - `GET /light`: Trả về dữ liệu JSON chứa trạng thái đèn hiện tại (Bật/Tắt, Độ sáng, Màu RGB).
     - `POST /light`: Nhận dữ liệu JSON từ client để điều khiển đèn.
2. **Mục 8.4 HTTPS Web Server (TLS Encryption, Cổng 443)**:
   - Sử dụng component `esp_https_server` để thiết lập kênh truyền bảo mật TLS/SSL.
   - Nhúng chứng chỉ máy chủ X.509 (`cacert.pem`) và khóa riêng tư RSA (`prvtkey.pem`) trực tiếp vào firmware.
   - Mã hóa toàn bộ dữ liệu trao đổi giữa trình duyệt client và ESP32, chống nghe lén và can thiệp trên mạng nội bộ.

## 2. Các Lỗi Kỹ Thuật Đã Khắc Phục Khi Lên ESP-IDF v6.0.2 & GCC 15

Mã nguồn gốc trong giáo trình (`test_case/https_server`) tồn tại các lỗi nghiêm trọng khiến dự án không thể biên dịch hoặc bị crash ngay khi khởi động:

1. **Lỗi đường dẫn component lỗi thời**:
   - *Nguyên nhân*: Tệp `CMakeLists.txt` gốc trỏ vào `../../Project/components/` vốn không tồn tại.
   - *Khắc phục*: Trỏ chính xác vào `${CMAKE_CURRENT_LIST_DIR}/../../device_firmware/components`.
2. **Lỗi sập trình biên dịch GCC 15 (ICE Protection)**:
   - *Khắc phục*: Bổ sung khiên bảo vệ `set(COMPONENTS main button app_storage light_driver nvs_flash esp_wifi esp_event esp_netif esp_https_server esp_http_server)`.
3. **Lỗi thiếu symbol chứng chỉ TLS khi liên kết (`_binary_cacert_pem_start`)**:
   - *Nguyên nhân*: `main/CMakeLists.txt` định nghĩa `COMPONENT_EMBED_TXTFILES` nhưng không truyền vào `idf_component_register`.
   - *Khắc phục*: Đăng ký tường minh `EMBED_TXTFILES "cacert.pem" "prvtkey.pem"` trong `idf_component_register`.
4. **Lỗi thẩm định nạp chứng chỉ HTTPS trên ESP-IDF v6.0.2**:
   - *Nguyên nhân*: Mã nguồn cũ gán chứng chỉ máy chủ vào `conf.cacert_pem` (dành cho client verification/mTLS). Trên ESP-IDF v6, việc thiếu `conf.servercert` sẽ làm hàm `httpd_ssl_start` báo lỗi `No Server certificate supplied` (`ESP_ERR_INVALID_ARG 0x102`) và sập hệ thống.
   - *Khắc phục*: Gán đúng `conf.servercert = cacert_pem_start` và `conf.servercert_len`.
5. **Mã nguồn gốc chỉ để dummy TODO**:
   - *Nguyên nhân*: Hàm `esp_light_set_handler` trong giáo trình chỉ in log `%.*s` kèm chú thích `// TODO: 读到数据后解析并且操作灯` mà không thực sự điều khiển đèn!
   - *Khắc phục*: Hiện thực hóa bộ phân tích JSON đầy đủ, điều phối trạng thái, độ sáng, đổi màu và tích hợp giao diện Web Dashboard hoàn chỉnh.

## 4. Các Tính Năng Hiện Đại Được Bổ Sung

### 4.1. Giao Diện Web Dashboard Tương Tác Trực Tiếp (`GET /`)
Khi người dùng mở trình duyệt web trên máy tính hoặc điện thoại và truy cập `https://<IP-ESP32>/`:
* **Thiết kế UI**: Dark Mode hiện đại, hiệu ứng Glassmorphism mượt mà.
* **Huy hiệu trạng thái trực quan**: Hiển thị rõ ràng "ĐÈN ĐANG BẬT" (viền xanh lá) hoặc "ĐÈN ĐANG TẮT" (viền đỏ).
* **Cụm nút điều khiển**: BẬT ĐÈN, TẮT ĐÈN, ĐỔI MÀU (8 màu RGB).
* **Thanh trượt độ sáng (Slider)**: Điều chỉnh từ 5% đến 100% theo thời gian thực.
* **Bảng chọn màu nhanh (Palette)**: 8 ô màu chọn nhanh (Đỏ, Xanh lá, Xanh dương, Vàng, Tím, Xanh lơ, Cam, Trắng ấm).
* **Tự động đồng bộ (Auto Sync)**: JavaScript ngầm gọi `GET /light` mỗi 2 giây để cập nhật trạng thái nếu có ai đó nhấn nút Boot vật lý trên mạch.

### 4.2. REST API `/light` Chuẩn Hóa
* **`GET /light`**:
  * Trả về JSON:
    ```json
    {
      "status": true,
      "brightness": 100,
      "color_index": 0,
      "color_name": "Đỏ (Red)",
      "color": {"r": 255, "g": 0, "b": 0}
    }
    ```
* **`POST /light`**:
  * Chấp nhận payload JSON linh hoạt:
    * Bật/Tắt: `{"status": true}` hoặc `{"status": false}`
    * Cử chỉ: `{"action": "toggle"}`, `{"action": "next_color"}`, `{"action": "brightness_up"}`, `{"action": "brightness_down"}`
    * Độ sáng: `{"brightness": 75}`
    * Màu RGB: `{"r": 0, "g": 255, "b": 0}` hoặc `{"red": 0, "green": 255, "blue": 0}`

### 4.3. Kịch Bản Python Kiểm Thử Đa Năng (`scripts/test_https_server.py`)
Hỗ trợ kiểm thử trực tiếp từ terminal với 2 chế độ:
```powershell

# Chế độ tự động Auto-Test 6 bước:
python test_case/https_server/scripts/test_https_server.py --host 192.168.1.31 --auto

# Kiểm thử với giao thức HTTP thường (nếu tắt TLS):
python test_case/https_server/scripts/test_https_server.py --host 192.168.1.31 --proto http
```

### Bước 3: Thao Tác Kiểm Thử
1. **Kiểm tra trên Trình duyệt Web (Chrome, Safari, Edge)**:
   - Mở trình duyệt trên điện thoại hoặc máy tính (cùng Wi-Fi).
   - Truy cập `https://192.168.1.x/` (chọn *Advanced* $\rightarrow$ *Proceed* nếu có cảnh báo chứng chỉ tự ký).
   - Bấm các nút BẬT, TẮT, ĐỔI MÀU, kéo thanh trượt độ sáng $\rightarrow$ Đèn LED WS2812B trên mạch đổi trạng thái tức thì.
2. **Kiểm tra bằng Kịch bản Python CLI**:
   ```powershell
   python test_case/https_server/scripts/test_https_server.py --host <IP-ESP32>
   ```
   - Nhập `0` $\rightarrow$ Tắt đèn
   - Nhập `1` $\rightarrow$ Bật đèn
   - Nhập `11` $\rightarrow$ Đổi màu RGB kế tiếp
   - Nhập `u` hoặc `d` $\rightarrow$ Tăng/giảm độ sáng
