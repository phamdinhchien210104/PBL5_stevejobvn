## 1. Mục Tiêu Cốt Lõi Của Chương 7

Trong mô hình kiến trúc IoT, sau khi đã hoàn thiện tầng driver thiết bị cơ sở (Chương 6 / Mục 6.5), thiết bị cần được trang bị khả năng giao tiếp mạng không dây:
1. **Khởi tạo Wi-Fi Station (STA) Mode chuẩn ESP-IDF v6**: Thiết lập ngăn xếp mạng TCP/IP LwIP, khởi tạo giao diện mạng mạng ảo (`esp_netif`), kích hoạt bộ xử lý sự kiện mặc định (`esp_event_loop_create_default`) và nạp cấu hình Wi-Fi.
2. **Đồng bộ hóa bất đồng bộ với FreeRTOS Event Groups**: Do quá trình kết nối Wi-Fi (quét mạng, bắt tay 4 bước WPA2, xin cấp phát DHCP IP) diễn ra bất đồng bộ và tốn nhiều thời gian, hệ thống sử dụng **FreeRTOS Event Groups** (`WIFI_CONNECTED_BIT`, `WIFI_FAIL_BIT`) để tác vụ `app_main` đồng bộ mà không chiếm dụng 100% CPU.
3. **Cơ chế phục hồi & Thử lại thông minh (Auto-Reconnect Strategy)**: Xử lý sự kiện ngắt kết nối (`WIFI_EVENT_STA_DISCONNECTED`) với số lần thử lại tối đa (`CONFIG_ESP_MAXIMUM_RETRY`), chống tắc nghẽn hoặc tràn tài nguyên khi Access Point (AP) bị tắt.
4. **Phản hồi thị giác trực quan qua Thanh LED WS2812B (Visual State Indication)**: Tích hợp trạng thái mạng không dây trực tiếp vào thanh 8 hạt LED NeoPixel:
   - **Đang kết nối**: Đèn thở (Breathing) màu Vàng/Cam.
   - **Kết nối thành công (Đã có IP)**: Đèn chuyển Xanh lá cây.
   - **Kết nối thất bại**: Đèn chuyển Đỏ cảnh báo.
5. **Cấu hình linh hoạt qua Kconfig (`menuconfig`)**: Loại bỏ việc hardcode thông tin SSID / Password cá nhân trong mã nguồn C, cho phép cấu hình độc lập qua Kconfig của ESP-IDF.

### 3.1. Sơ Đồ Khối Kiến Trúc Xử Lý Mạng (Wi-Fi Architecture Flow)

```text
+-------------------+      WIFI_EVENT_STA_START      +--------------------+
|                   | -----------------------------> |                    |
|   Khởi Động STA   |                                |  esp_wifi_connect  |
|                   | <----------------------------- |                    |
+-------------------+   WIFI_EVENT_STA_DISCONNECTED  +--------------------+
         |                                                     |
         | (Retry < 5)                                         | (Got IP)
         v                                                     v
+-------------------+                                +--------------------+
|  Thử lại kết nối  |                                | IP_EVENT_STA_GOT_IP|
| (Đèn thở Vàng/Cam)|                                | (Đèn Xanh lá cây)  |
+-------------------+                                +--------------------+
         | (Retry >= 5)                                        |
         v                                                     v
+-------------------+                                +--------------------+
|  WIFI_FAIL_BIT    |                                | WIFI_CONNECTED_BIT |
|    (Đèn báo Đỏ)   |                                |  (Khôi phục NVS)   |
+-------------------+                                +--------------------+
```

### 3.3. Tích Hợp Chỉ Báo Trạng Thái Thị Giác (`app_driver_set_wifi_status`)

Trong các thiết bị IoT thương mại, người dùng không thể theo dõi qua cổng Serial (UART) của máy tính. Việc phản hồi trạng thái mạng trực quan bằng màu sắc trên Thanh LED WS2812B là tính năng thiết yếu:

```c
void app_driver_set_wifi_status(wifi_status_t status)
{
    switch (status) {
    case WIFI_STATUS_CONNECTING:
        // Khi đang kết nối hoặc retry: Đèn chuyển sang hiệu ứng thở màu Vàng/Cam
        light_driver_set_switch(true);
        light_driver_breath_start(255, 160, 0);
        break;

    case WIFI_STATUS_CONNECTED:
        // Khi đã nhận được IP: Dừng thở và bật màu Xanh lá cây
        light_driver_breath_stop();
        light_driver_set_switch(true);
        light_driver_set_rgb(0, 255, 0);
        break;

    case WIFI_STATUS_FAILED:
        // Khi thất bại sau 5 lần thử: Đèn bật màu Đỏ cảnh báo
        light_driver_breath_stop();
        light_driver_set_switch(true);
        light_driver_set_rgb(255, 0, 0);
        break;
    }
}
```

## 4. Hướng Dẫn Thao Tác Kiểm Thử Thực Tế

### 4.1. Cấu hình Wi-Fi mạng gia đình qua `menuconfig`
```powershell
idf.py -C device_firmware/3_wifi_connection menuconfig
```
- Vào menu **Example Configuration**:
  - `WiFi SSID`: Điền tên Wi-Fi nhà bạn.
  - `WiFi Password`: Điền mật khẩu Wi-Fi.
- Bấm `S` để lưu và `ESC` để thoát.

### 4.2. Biên dịch và Nạp firmware (ESP32-S3)
```powershell
# Đặt chip mục tiêu S3 (nếu chuyển target)
idf.py -C device_firmware/3_wifi_connection set-target esp32s3

# Biên dịch, nạp và mở log monitor
idf.py -C device_firmware/3_wifi_connection -p COM4 flash monitor
```

## 5. Kết Luận & Kế Hoạch Bước Kế Tiếp

- **Chương 3 (`3_wifi_connection`)** đã hiện thực hóa trọn vẹn lý thuyết kết nối mạng của giáo trình Espressif, đồng thời nâng cấp vượt bậc với phần cứng thực tế của nhóm (Thanh 8 LED WS2812B SPI DMA + Kconfig linh hoạt + Đa mục tiêu S3/C3).
- Toàn bộ nền tảng Wi-Fi và Driver đã hoàn tất để chuẩn bị cho:
  - **Chương 4 (`4_network_config`)**: Tích hợp cấu hình Wi-Fi qua Bluetooth Low Energy (BLE Provisioning) trực tiếp từ App điện thoại.
  - **Chương 5 (`5_rainmaker`)**: Kết nối Cloud ESP RainMaker để điều khiển đèn thông minh qua Internet từ bất cứ đâu.
